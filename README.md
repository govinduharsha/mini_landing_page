# 🚀 Nexcent — Minimal Landing Page

A modern, responsive agency landing page built with **Next.js 14**, **TypeScript**, and **Tailwind CSS**, recreated from the Nexcent Figma design.

## ✨ Features

* 🎨 Pixel-perfect Figma-inspired UI
* 📱 Fully responsive design
* ⚡ Next.js 14 App Router
* 🧩 Reusable React components
* ♾️ Infinite scrolling client marquee
* ✨ Scroll-triggered animations
* 🎯 Responsive navigation and CTA sections
* 🖼️ Optimized static assets
* 🚀 Production-ready frontend architecture

## 🛠️ Tech Stack

* **Next.js 14**
* **React**
* **TypeScript**
* **Tailwind CSS**
* **Inter Font**
* **Vercel**

## 🚀 Getting Started

Clone the repository:

```bash
git clone https://github.com/ghv061101/mini_landing_page.git
cd mini_landing_page
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Open http://localhost:3000 in your browser.

## 📦 Production Build

```bash
npm run build
npm start
```

## 🌐 Deployment

The project can be deployed using **Vercel**.

Connect the GitHub repository to Vercel, or deploy using the Vercel CLI.
